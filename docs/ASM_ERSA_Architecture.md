## 一、架构概述

ASM-ERSA 是一种混合线性-稀疏注意力 Transformer 架构，核心特点在于将 Gated DeltaNet 的标量门控升级为通道级向量门控（ASM-ERSA），并以 Native Sparse Attention（NSA）替代传统全注意力层，实现长上下文场景下的算力与性能帕累托优化。

### 1.1 设计动机

传统 Gated DeltaNet（GDN）使用标量遗忘门 α_t 和标量写入强度 β_t，所有通道共享同一衰减和写入策略。这一设计在短上下文下表现良好，但在长序列建模中存在两个瓶颈：

1. **擦除粒度不足**：标量 β_t 无法区分不同语义通道的重要性差异，导致关键信息被过度擦除或冗余信息未被充分清除
2. **写入选择性缺失**：所有 value 通道以相同强度写入，无法实现"保留某些维度、覆盖另一些维度"的精细控制

ASM-ERSA通过将这两个标量扩展为通道级向量，使模型在每一步递推中都能做出更精细的记忆管理决策。

### 1.2 整体架构

│  │ ASM-ERSA │  │ ASM-ERSA │  │ ASM-ERSA │  │ NSA      │   │
│  │ Layer 0  │  │ Layer 1  │  │ Layer 2  │  │ Layer 3  │   │

│  │ ASM-ERSA │  │ ASM-ERSA │  │ ASM-ERSA │  │ NSA      │   │
│  │ Layer 4  │  │ Layer 5  │  │ Layer 6  │  │ Layer 7  │   │

| 模块 | 作用 | 层数 |
|------|------|------|

## 二、ASM-ERSA模块（核心特点）

### 2.1 与 GDN 的区别

| 维度 | GDN（基线） | ASM-ERSA（本架构） |
|------|------------|----------------|
| 擦除门控 | 标量 β_t ∈ ℝ | 通道级向量 b_t ∈ [0,1]^{d_k} |
| 写入门控 | 标量 β_t（与擦除共享） | 通道级向量 w_t ∈ [0,1]^{d_v}，独立于擦除 |
| 衰减 | 标量 α_t ∈ ℝ | 通道级对角矩阵 D_t = diag(α_t)，α_t ∈ (0,1]^{d_k} |
| 退化关系 | — | b_t = β_t·1, w_t = β_t·1 时退化为 GDN |

### 2.2 状态递推公式

每头维护状态矩阵 S_t ∈ ℝ^{d_v × d_k}，ASM-ERSA的递推为：

```
S_t = (I − k_t (b_t ⊙ k_t)ᵀ) · D_t · S_{t−1} + k_t (w_t ⊙ v_t)ᵀ
```

其中：

- `b_t = σ(W_b · x_t) ∈ [0,1]^{d_k}` — 通道级擦除门
- `w_t = σ(W_w · x_t) ∈ [0,1]^{d_v}` — 通道级写入门
- `α_t = exp(−exp(A_log) · softplus(a_t + dt_bias)) ∈ (0,1]^{d_k}` — 通道级衰减
- `D_t = diag(α_t)` — 衰减对角矩阵
- `k_t, q_t` — L2 归一化的 key 和 query
- `v_t` — L2 归一化的 value

### 2.3 递推分解

递推可分解为三步理解：

**第一步：通道级衰减**

```
S̃ = D_t · S_{t−1} = diag(α_t) · S_{t−1}
```

对状态矩阵的每一列（对应 key 空间的一个通道）施加独立的衰减系数。不同通道可以有不同的遗忘速度。

**第二步：通道级擦除**

```
S̃' = S̃ − k_t ⊗ ((b_t ⊙ k_t)ᵀ · S̃)
```

擦除算子 `(I − k_t (b_t ⊙ k_t)ᵀ)` 中，`b_t ⊙ k_t` 使擦除在 key 轴上具有通道选择性。当 `b_t` 的某个分量为 0 时，对应 key 通道不做任何擦除；当为 1 时，执行完全擦除。

**第三步：通道级写入**

```
S_t = S̃' + k_t ⊗ (w_t ⊙ v_t)ᵀ
```

写入项 `k_t (w_t ⊙ v_t)ᵀ` 中，`w_t ⊙ v_t` 使写入在 value 轴上具有通道选择性。模型可以选择性地只更新某些 value 通道，保留其他通道的已有信息。

### 2.4 输出计算

```
o_t = q_t · S_t ∈ ℝ^{d_v}
```

对所有头拼接后经过线性投影得到最终输出：

```
output = W_o · concat(o_t^{(1)}, ..., o_t^{(H)})
```

### 2.5 参数列表

| 参数 | 形状 | 说明 |
|------|------|------|
| W_q | [d_model, H·d_k] | Query 投影 |
| W_k | [d_model, H·d_k] | Key 投影 |
| W_v | [d_model, H·d_v] | Value 投影 |
| W_o | [H·d_v, d_model] | 输出投影 |
| W_b | [d_model, H·d_k] | 擦除门投影 |
| W_w | [d_model, H·d_v] | 写入门投影 |
| W_a | [d_model, H·d_k] | 衰减参数投影 |
| A_log | [H, d_k] | 可学习衰减偏置 |
| dt_bias | [H, d_k] | 衰减时间步偏置 |

## 三、NSA 模块（稀疏注意力）

### 3.1 设计目标

NSA 替代传统全注意力层，在保持全局检索能力的同时将每 query 的注意力计算量从 O(n) 降至 O(k_c + k_f + w)，其中 k_c、k_f、w 均为与序列长度 n 无关的常数。

### 3.2 三分支架构

```
                    ┌─────────────────────────┐
                    │      当前 token q_t      │
                    └────────┬────────────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
     ┌────────────┐  ┌────────────┐  ┌────────────┐
     │ 压缩注意力  │  │ 选择注意力  │  │ 滑动窗口    │
     │ (Coarse)   │  │ (Fine)     │  │ (Local)    │
     │            │  │            │  │            │
     │ stride=64  │  │ 候选集     │  │ window     │
     │ top-32     │  │ top-256    │  │ =1024      │
     └─────┬──────┘  └─────┬──────┘  └─────┬──────┘
           │               │               │
           ▼               ▼               ▼
        y_coarse       y_fine         y_local
           │               │               │
           └───────┬───────┘               │
                   │                       │
              α_c ⊗ y_coarse         α_l · y_local
              α_f ⊗ y_fine               │
                   │               │       │
                   └───────────────┴───────┘
                              │
                    y_NSA = y_local + α_c·y_coarse + α_f·y_fine
```

### 3.3 分支 1：压缩注意力（Coarse-Grained）

对全序列的 key 和 value 做跨步平均池化压缩，然后在压缩表示上做 top-k 选择：

```
# 池化压缩
K̃_j = (1/s) · Σ_{t=(j-1)s+1}^{js} k_t,    s = 64
Ṽ_j = (1/s) · Σ_{t=(j-1)s+1}^{js} v_t

# 块级评分（多头 ReLU 点积求和）
score_j = Σ_h relu(q_{t,h} · RMSNorm(K̃_j) · RoPE(j·s)) / √D

# Top-k 选择
C = top_k(scores, k=32)

# 压缩注意力
y_coarse = Attention(q_t, K̃_C, Ṽ_C)
```

### 3.4 分支 2：精确选择注意力（Fine-Grained）

直接选择单个 token 位置，而非选择块再展开：

```
# 候选集构建：高分块邻域 + 近期 token
candidate_set = {j·s ± s/2 : j ∈ C} ∪ {t-w, ..., t-1}

# 精确评分
score_i = Σ_h relu(q_{t,h} · k_i · RoPE(i)) / √D,    i ∈ candidate_set

# Top-k 精确选择
S = top_k(scores, k=256)

# 精确注意力
y_fine = Attention(q_t, K_S, V_S)
```

### 3.5 分支 3：滑动窗口注意力（Local）

标准局部注意力，保证近距离信息无损：

```
y_local = Attention(q_t, K_{t-w:t}, V_{t-w:t}),    w = 1024
```

### 3.6 三分支融合

采用残差式融合，滑动窗口为基础，门控叠加压缩和选择分支：

```
α_c = σ(W_gate_c · x_t) ∈ [0,1]^H
α_f = σ(W_gate_f · x_t) ∈ [0,1]^H

y_NSA = y_local + α_c ⊗ y_coarse + α_f ⊗ y_fine
```

### 3.7 算力分析

以 1M token 上下文、H=32 头、d_k=128 为基准：

| 操作 | QSA 基线 | NSA | 加速比 |
|------|---------|-----|--------|
| 池化/压缩 | 250K 次（stride=4） | 15.6K 次（stride=64） | 16× |
| 评分 | 250K × d_k | 15.6K × d_k + 2.3K × d_k | ~10× |
| 精确注意力 | 2048 × d_k | 256 × d_k | 8× |
| 滑动窗口 | 无 | 1024 × d_k | 新增 |
| **总计** | **1.0×** | **~0.5×** | **~2×** |

## 四、Gated Residual 模块

### 4.1 设计动机

传统 Transformer 使用单一残差流，层数增加后早期信息容易被稀释。ASM-ERSA 将残差流扩展为 4 条并行分支，通过动态门控控制信息的读取和写入。

### 4.2 GR Read（读取）

对 4 条残差分支分别做 RMSNorm，预测逐分支读取门，再加权平均得到子层输入：

```
x = (1/4) · Σ_{i=1}^{4} g_i ⊙ RMSNorm(R_i)
```

其中：

```
g_i = σ(W_read · concat(R₁, R₂, R₃, R₄)) ∈ [0, 1]
```

读取门经 sigmoid 约束在 [0, 1] 范围内，允许模型选择性地从某些分支读取更多信息。

### 4.3 GR Write（写入）

子层输出 y 后，为每条分支预测标量写入门，分别执行残差加法：

```
R'_i = R_i + s_i · y,    i = 1, 2, 3, 4
```

其中：

```
s_i = 2 · σ(W_write · y) ∈ [0, 2]
```

写入门范围为 [0, 2]，允许放大（s > 1）或缩小（s < 1）子层输出的贡献。

### 4.4 每层调用序列

每个 Transformer 块内 GR 被调用两次：

1. 第一次：围绕 Token Mixing 子层（ASM-ERSA或 NSA）
2. 第二次：围绕 MoE 子层

## 五、MoE 模块

### 5.1 路由机制

每个 MoE 层包含 512 个路由专家 + 1 个共享专家，每 token 选择 top-10 路由专家：

```
g(x) = softmax(TopK(x · W_g, k=10))
```

TopK 仅保留分数最高的 10 个专家，其余置为 −∞ 后再做 softmax。

### 5.2 专家聚合

```
output = Σ_{i ∈ TopK} g_i(x) · E_i(x) + E_shared(x)
```

共享专家 E_shared 对所有 token 提供通用变换，不参与路由选择。

### 5.3 专家结构

每个路由专家为两层 SwiGLU 变换：

```
E_i(x) = W2_i · SiLU(W1_i · x)
```

## 六、完整前向传播

### 6.1 单 Token 推理流程

```
输入：token_id → Embedding → x ∈ ℝ^{d_model}

初始化 4 条残差分支：R₁ = R₂ = R₃ = R₄ = x

对于每一层 layer_idx = 0, 1, ..., 47：

    ┌─ 第 1 次 GR Read ─────────────────────────────────┐
    │ x = (1/4) · Σ g_i ⊙ RMSNorm(R_i)                 │
    └────────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─ Token Mixing ─────────────────────────────────────┐
    │ if layer_idx % 4 != 3:                             │
    │     y = ASM-ERSA(x)    # 通道级门控线性注意力       │
    │ else:                                              │
    │     y = NSA(x, kv_buffer, positions)               │
    └────────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─ 第 1 次 GR Write ────────────────────────────────┐
    │ R_i = R_i + s_i · y,    i = 1..4                  │
    └────────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─ 第 2 次 GR Read ─────────────────────────────────┐
    │ x = (1/4) · Σ g_i ⊙ RMSNorm(R_i)                 │
    └────────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─ MoE ─────────────────────────────────────────────┐
    │ y = MoE(x)    # 512 专家 top-10 + 共享专家         │
    └────────────────────────────────────────────────────┘
                        │
                        ▼
    ┌─ 第 2 次 GR Write ────────────────────────────────┐
    │ R_i = R_i + s_i · y,    i = 1..4                  │
    └────────────────────────────────────────────────────┘

最终输出：GR Read 将 4 条分支压缩为单一向量 → RMSNorm → LM Head → logits
```

### 6.2 ASM-ERSA层内部流程

```
输入：x ∈ ℝ^{d_model}

1. 投影：q = W_q·x, k = W_k·x, v = W_v·x
2. L2 归一化：q = q/‖q‖, k = k/‖k‖
3. 门控生成：
   b = σ(W_b·x) ∈ [0,1]^{H×d_k}     # 擦除门
   w = σ(W_w·x) ∈ [0,1]^{H×d_v}     # 写入门
   α = exp(−exp(A_log)·softplus(W_a·x + dt_bias))  # 衰减
4. 状态递推：
   S̃ = diag(α) · S_{t-1}             # 衰减
   S̃' = S̃ − k ⊗ ((b⊙k)ᵀ · S̃)       # 擦除
   S_t = S̃' + k ⊗ (w⊙v)ᵀ            # 写入
5. 输出：o = q · S_t → W_o → output
```

### 6.3 NSA 层内部流程

```
输入：x ∈ ℝ^{d_model}, kv_buffer ∈ ℝ^{t×H×(d_k+d_v)}

1. 投影：q = W_q·x
2. 从 kv_buffer 读取 K_all, V_all

3. 分支 1（压缩）：
   K̃ = pool(K_all, stride=64)
   scores = Σ_h relu(q·RMSNorm(K̃)·RoPE) / √D
   C = top_k(scores, k=32)
   y_coarse = Attn(q, K̃[C], Ṽ[C])

4. 分支 2（选择）：
   candidates = neighbors(C) ∪ recent_window
   scores = Σ_h relu(q·K_cand·RoPE) / √D
   S = top_k(scores, k=256)
   y_fine = Attn(q, K[S], V[S])

5. 分支 3（局部）：
   y_local = Attn(q, K_{t-1024:t}, V_{t-1024:t})

6. 融合：
   α_c = σ(W_gate_c·x)
   α_f = σ(W_gate_f·x)
   y_NSA = y_local + α_c·y_coarse + α_f·y_fine
   output = W_o·y_NSA
```

## 七、动态稀疏嵌入（Dynamic Sparse Embedding）

### 7.1 设计动机

完整的 N-gram 嵌入表（2000 万条目 × 4096 维 ≈ 81.9B 参数）存储开销巨大。ASM-ERSA 采用动态稀疏嵌入策略，将 N-gram 嵌入压缩至 100 万条目（≈ 4.1B 参数），实现 10.7× 压缩。

### 7.2 架构

```
输入 token_ids: [B, T]
    │
    ├──────────────────────────────────┐
    ▼                                  ▼
┌──────────────────┐         ┌──────────────────────┐
│ base_embed       │         │ n-gram 哈希计算       │
│ (152K × 2560)    │         │ h = Σ t_i·p^(n-i) mod M │
│ 完整存储          │         │                      │
└────────┬─────────┘         └──────┬───────────────┘
         │                          │
         │                   ┌──────┴──────┐
         │                   ▼             ▼
         │            ┌──────────┐  ┌──────────────┐
         │            │ 稀疏查表  │  │ 动态组合生成  │
         │            │ ngram_   │  │ combine_proj  │
         │            │ embed    │  │ (拼接→投影)   │
         │            │ (100万)  │  │              │
         │            └────┬─────┘  └──────┬───────┘
         │                 │               │
         │                 └───────┬───────┘
         │                         ▼
         │                ┌────────────────┐
         │                │ 融合门控        │
         │                │ gate_proj → softmax │
         │                │ 查表 vs 动态生成 │
         │                └────────┬───────┘
         │                         │
         └────────── + ────────────┘
                     ▼
              output: [B, T, d_model]
```

### 7.3 核心组件

| 组件 | 参数形状 | 参数量 | 说明 |
|------|---------|--------|------|
| base_embed | [248320, 2560] | 635M | 基础词嵌入，完整存储 |
| ngram_embed | [1000000, 2560] | 2.56B | 高频 n-gram 稀疏表 |
| combine_proj | [5120, 2560] | 13.1M | 动态组合投影 |
| gate_proj | [5120, 2] | 10K | 查表/动态融合门控 |
| LRU Cache | [100000, 2560] | 256M | 运行时热数据缓存 |
| **总计** | | **~3.46B** | 对比完整 N-gram 表的 ~82.5B |

### 7.4 哈希策略

使用多项式哈希将 n-gram token 序列映射到稀疏表索引：

```
h = (t_0 · p^(n-1) + t_1 · p^(n-2) + ... + t_{n-1}) mod M
```

其中 p = 1000003（大素数），M = 1000000（表大小）。

### 7.5 融合门控

对每个 n-gram 位置，门控网络决定使用查表结果还是动态组合结果：

```
gates = softmax(gate_proj(concat(h_table, h_dynamic)))
h_ngram = gates[0] · h_table + gates[1] · h_dynamic
output = h_base + h_ngram
```

## 十、架构差异说明

### 10.1 为何不迁移外部权重

ASM-ERSA 的核心设计（ASM-ERSA通道级门控、NSA 三分支稀疏注意力、动态稀疏嵌入）与同类基线存在根本性架构差异：

1. **门控维度不匹配**：基线使用标量门控 β_t，ASM-ERSA 使用通道级向量门控 b_t ∈ ℝ^{d_k}、w_t ∈ ℝ^{d_v}，无法直接映射
2. **稀疏注意力结构不同**：QSA（micro-block top-512）与 NSA（stride-64 压缩 + top-32/top-256 三分支）的算法流程完全不同
3. **嵌入层规模差异**：完整 N-gram 表（~82B 参数）vs ASM-ERSA 的动态稀疏嵌入（~3.5B 参数），压缩比 24×
4. **隐藏层维度不同**：基准配置 d_model=4096 vs 基线的 2560，3B 配置 d_model=2048 同样不匹配
5. **新增参数无对应**：ASM-ERSA的 W_a（衰减投影）、NSA 的 W_gate_c/W_gate_f（融合门控）在基线中无对应参数

这些差异意味着即使做复杂的权重变换，迁移后的模型也需要大量微调才能恢复性能，不如直接从头训练。

### 10.2 模块划分与层比例

ASM-ERSA 的模块划分与层比例：

- 每 4 层为 3 层 ASM 槽位记忆 + 1 层 ERSA 精确回召；
- MoE 512 专家 top-10 路由、4 分支残差流；
- 长上下文处理走 ASM 槽位状态 + ERSA 精确回召。

## 十二、ASM-ERSA的理论优势

### 12.1 表达能力

GDN 的标量门控可以视为 ASM-ERSA通道级门控的特例：

```
GDN:  b_t = β_t · 1_{d_k},  w_t = β_t · 1_{d_v},  D_t = α_t · I
ASM-ERSA: b_t ∈ [0,1]^{d_k},   w_t ∈ [0,1]^{d_v},   D_t = diag(α_t)
```

因此 ASM-ERSA的表达能力严格大于 GDN，且当训练数据不足以支撑通道级门控的学习时，ASM-ERSA可以自然退化为 GDN 的行为。

### 12.2 记忆管理精细度

GDN 在每一步只能做出"整体保留"或"整体擦除"的决策；ASM-ERSA可以对不同语义通道做出不同决策。例如：

- 通道 1-32（语法信息）：高擦除、低写入 → 快速更新语法状态
- 通道 33-64（语义信息）：低擦除、高写入 → 稳定积累语义表示
- 通道 65-128（事实信息）：中擦除、中写入 → 平衡更新

这种通道级精细控制是标量门控无法实现的。

### 12.3 与 KDA 的关系

KDA（Kimi Delta Attention）引入了通道级衰减 D_t = diag(α_t)，但擦除和写入仍使用标量 β_t。ASM-ERSA在 KDA 的基础上进一步将擦除和写入也通道化：

```
KDA:   S_t = (I − β_t · k_t k_tᵀ) · D_t · S_{t-1} + β_t · k_t v_tᵀ
ASM-ERSA: S_t = (I − k_t (b_t ⊙ k_t)ᵀ) · D_t · S_{t-1} + k_t (w_t ⊙ v_t)ᵀ
```

当 b_t = β_t·1, w_t = β_t·1 时，ASM-ERSA精确退化为 KDA。

## 十三、实现要点

### 13.1 数值稳定性

- Key 和 Query 必须做 L2 归一化，防止外积更新时数值爆炸
- 衰减 α_t 通过对数空间计算：`α = exp(−exp(A_log) · softplus(...))`，确保 α ∈ (0, 1]
- 状态矩阵 S 建议用 FP32 维护，避免 FP16 下长序列递推的精度累积误差

### 13.2 Chunkwise WY 算法

ASM-ERSA保留硬件友好的 chunkwise WY 算法，将序列按固定长度分块：

- 块内递推通过 WY 表示展开为矩阵乘法
- 块间以循环状态传递
- 通道级衰减可吸收至非对称擦除因子中

### 13.3 NSA 的 KV 缓冲区管理

NSA 层需要访问全序列的 key 和 value，需要维护显式 KV 缓冲区：

- 建议按 64-token chunk 分页管理
- 压缩分支可用 INT8 量化存储（对精度不敏感）
- 精确分支和滑动窗口分支用 BF16
- 支持异步 Prefetch 从主机内存加载

### 13.4 训练建议

- 压缩分支的 top-k 不可微，需要 straight-through estimator
- 建议先用 GDN（标量门控）预训练至收敛，再切换为 ASM-ERSA微调
- NSA 的融合门控 α_c, α_f 初始化建议偏小（sigmoid 输入偏负），让滑动窗口分支在训练初期主导
